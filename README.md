# MIT212 - Programming Techniques – Week 04 Lab Test

## Overview
This repository contains the week 04 lab test for MIT212 - Programming Techniques.

## Files Included
- **hello.py** - Initial Python program with greeting messages (Version 1 and Version 2)
- **calculator.py** - Simple calculator with basic arithmetic functions

## Getting Started

### Clone the Repository
```bash
git clone https://github.com/ravinduwajira/week04-lab
cd week04-lab
```

### Running the Programs

**Hello Program:**
```bash
python hello.py
```

**Calculator:**
```bash
python calculator.py
```
